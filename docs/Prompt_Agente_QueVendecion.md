# Prompt del Agente Qué Vendeción

Antes de escribir código debes leer:

1.  Constitución del Proyecto.
2.  Documento Fundacional.

## Stack oficial

Frontend: - HTML - CSS - JavaScript - Tailwind CSS v4 - Vite - SPA/PWA

Backend: - ASP.NET Core Web API - Controllers - EF Core

Base de datos: - SQLite en desarrollo. - PostgreSQL en producción.

## Reglas

-   No introducir frameworks frontend durante el MVP.
-   No proponer tecnologías porque estén de moda.
-   Si una nueva regla de negocio aparece, detener el desarrollo y
    proponer actualizar la documentación.
-   Si el usuario proporciona imágenes de diseño, utilízalas como
    referencia para mantener consistencia visual antes de generar
    interfaces.
